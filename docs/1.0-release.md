# MotionForge 1.0 source-baseline evidence

This document records the gates run for the repository's 1.0.0 source/API
baseline. This checkout has no verifiable `v1.0.0` tag or npm publication
receipt, so the evidence must not be cited as proof that 1.0.0 was externally
published. External releases follow [release-process.md](release-process.md).

MotionForge 1.0 freezes Scene v1 and the public package/tool contracts after
the roadmap's source-of-truth, scene, extension, primitive, animation, media,
export, and agent-tool milestones.

## Required gates

- strict typecheck, unit tests, determinism/schema/migration/package lint;
- deterministic scene/patch fuzzing;
- canonical/migratable example corpus validation;
- pinned Chromium pixel/media/audio/stream/tool goldens;
- Chromium, Firefox, and WebKit renderer probes;
- browser workflow E2E;
- long-scene resource checks;
- pinned performance budgets;
- agent-eval mechanical scoring tests;
- dry-run pack for every public package;
- clean tarball install/build outside the monorepo.

## Reproducible commands

```sh
pnpm release:full
pnpm verify:clean
```

Pinned browser versions come from the workspace Playwright lock. Fuzzing uses
seed `0x5eed1234`. Performance uses 1280×720, 30 fps, 2 seconds, a 100 ms/frame
ceiling, and a 256 MiB JS heap ceiling.

## 1.0 baseline (Apple Silicon, pinned Chromium)

- render + encode: 6.27–6.32 ms/frame;
- one decoded video + caption: 6.04–6.38 ms/frame;
- two decoded videos: 6.15–6.76 ms/frame;
- heaviest JS heap snapshot: 20 MiB;
- 750 fuzz scenes / 2,250 evaluated frames;
- 28 curated corpus scenes;
- Chromium, Firefox, WebKit probes: pass.

CI repeats the full gate on Linux with all three Playwright browser engines.
See [compatibility.md](compatibility.md) for the 1.x contract.
