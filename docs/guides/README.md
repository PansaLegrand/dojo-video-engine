# Programmer Guides

- [Authoring API](authoring-api.md): scene helpers, timing, media nodes, and the core escape hatch.
- [Preset Catalog](preset-catalog.md): robust text overlays, subtitle templates, media looks, layouts, and transition names.
- [Animation Guide](animation.md): presets, raw keyframes, easing, and timeline choreography.
- [Media Guide](media.md): local assets, images, video, audio, fonts, Lottie, and current limits.
- [Preview And Export](preview-export.md): host integration, player API, export API, and direct rendering.
- [Dojo Video Engine vs Remotion](dojo-video-engine-vs-remotion.md): where Dojo Video Engine intentionally differs.
- [Agent-Generated Scenes](agent-generated-scenes.md): validation and patching loops for LLMs and coding agents.
