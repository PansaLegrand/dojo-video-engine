# Dojo Video Engine 1.1 performance report

Status: source candidate evidence
Date: 2026-08-26
Reference machine: the maintainer's local release-gate machine; results are not
portable device guarantees.

## 720p encode/decode gate

Budget: at most 100 ms/frame and 256 MiB JS heap at 1280×720@30.

| Scenario                     |                Result |
| ---------------------------- | --------------------: |
| Render + encode, no decode   | 6.22 ms/frame; 21 MiB |
| One video + caption          | 5.98 ms/frame; 25 MiB |
| Two videos, full + PiP at 2× | 6.20 ms/frame; 33 MiB |

## Compositing/cache gate

| Size      | Cache-hit render |        Peak bounded scratch | Static cache | Exact disabled-cache oracle |
| --------- | ---------------: | --------------------------: | -----------: | --------------------------- |
| 1920×1080 |    1.81 ms/frame |  63.86 MiB established peak |    14.44 MiB | Pass                        |
| 3840×2160 |    1.95 ms/frame | 258.83 MiB established peak |    57.66 MiB | Pass                        |

The clean external Vite build emits a 360.79 kB main module (99.14 kB gzip)
and an 833.39 kB export-worker module. These are uncompressed build artifacts,
not network-transfer guarantees; their sizes are now recorded as a baseline for
future code-splitting work.

The browser evidence renderer additionally caps dimensions, pixels, owned
Canvas bytes/surfaces, encoded bytes, artifact counts, and store residency.
Full-size still/visual-diff surfaces are released after bounded thumbnails are
retained for the terminal contact sheet. A 4K multi-row plan that cannot fit
the configured decoded-raster budget fails before allocation.

Run:

```sh
pnpm performance:gate
pnpm resource:smoke
```

See [`../benchmarks.md`](../benchmarks.md) for the stable gate definitions and
device-tier budgets.
