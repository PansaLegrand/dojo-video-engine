## Capability policy

Exact-pixel claims apply only to the pinned Chromium/font/color environment.
Firefox/WebKit evidence is capability/tolerance oriented. WebCodecs, codec,
File System Access, OffscreenCanvas, background-tab, and storage capabilities
must be preflighted; unsupported combinations fail rather than silently switch
semantics.

## Manual evidence not claimed

technology matrix, or GPU/vendor matrix was run for this source candidate.
Those rows remain a downstream/release-operator check and must not be inferred
from the three desktop browser engines.
