# Dojo Video Engine 1.1.5 — 2026-11-06

Status — all 16 public packages published with MIT licenses and npm provenance.

Preview now follows the available audio clock without a one-frame tolerance and
samples wall time once per update. The first frame stays steady while the initial
audio chunk prepares, eliminating startup forward/backward frame oscillation.
The correction builds on 1.1.4's fix for repeated audio restarts. Scene v1 and
public APIs are unchanged.

## Verification

The affected live DojoClip editor showed backward transport steps of
`0.00 → 0.03 → 0.00` and `0.17 → 0.13` seconds on 1.1.4. A separate browser
regression with a 400 ms initial audio decode delay reproduced repeated
`0.00 → 0.03 → 0.00` oscillation.

New regressions fail on the previous player. All 50 player/mixer tests pass with
the fix, covering delayed mixing, one-frame lag, a frame boundary crossed during
an update, and genuine looping. Real browser PCM decoding and Web Audio emit
forward-only startup frames while starting audio once.

The local full release and clean-machine package gates passed. An isolated
harness consumer passed its production build, 368 tests and browser playback/
export workflows against the candidate tarballs. Hosted macOS/Linux CI and both
candidate and tag-bound release gates passed. The first PR Linux attempt was
cancelled during slow Ubuntu dependency downloads; the replacement passed.

The tag signature, Rekor entry and workflow certificate identity were verified
locally. Anonymous registry reads checked SHA-256, SHA-512 and provenance metadata
for all 16 tarballs against the final hosted release bundle. Consumer adoption
and live deployment verification are recorded by each application separately.

A fresh registry-only installation passed `npm audit signatures`: all 27 registry
signatures and 21 attestations in the release dependency graph verified.
