# Dojo Video Engine 1.3.1

The dataChart macro accepts an optional palette with background, text, marks and axis colors. This supports briefs with a specific palette directly in the structured macro. Omitted fields preserve the 1.3.0 output, including its geometry, animation and default colors. Scene v1 remains compatible.

The chart browser regression measures ivory surface pixels, green bar lengths and the zero baseline in shuffled previews and every decoded MP4 frame. Unit tests cover both bar and line palette propagation, invalid colors and unchanged geometry. The release uses the existing signed-tag workflow and synchronized 17-package set.
