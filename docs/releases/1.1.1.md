## Trusted publishing

[Token-free verification](https://github.com/PansaLegrand/dojo-video-engine/actions/runs/41270057546)
added and removed a temporary dist-tag on every package with an empty npm token.
Each trust configuration is restricted to this repository, `release.yml`, and
the `npm-release` environment. The bootstrap npm token was revoked and the
GitHub environment's `NPM_TOKEN` secret was deleted. Future publishing uses OIDC
without a persistent-token fallback. Release tags remain immutable.
