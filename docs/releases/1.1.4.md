# Dojo Video Engine 1.1.4 — 2026-11-05

Status — all 16 public packages published with MIT licenses and npm provenance.

Looped preview now distinguishes a backward audio-clock correction from an
end-of-video loop. A slow initial audio decode previously caused repeated audio
restarts, cancelling the pending mix and trapping playback near its first frame.
The fix lets that mix finish and retains normal end-of-video looping.

## Verification

The regression failed on the previous implementation with seven audio starts
within twelve simulated ticks. The corrected player starts audio once, advances
when its initial mix becomes ready and starts again at a genuine loop boundary.
All 48 player/mixer tests passed.

The real-browser regression delays audio source reads by 400 ms while using real
PCM decoding and Web Audio. Playback advanced to frame 32 after 1.5 seconds with
one audio start. The local full-release and clean-package gates passed, followed
by hosted macOS/Linux CI, candidate qualification and the tag-bound release gates.

The tag signature, Rekor entry and workflow certificate identity were verified
locally. Anonymous registry reads checked SHA-256, SHA-512 and provenance metadata
for all 16 tarballs against the final hosted release bundle. The existing Scene v1
and player interfaces apply to this patch.

A clean harness candidate passed its build, tests and browser workflows against
the retained candidate packages. Application adoption and deployment are recorded
by each consumer separately.
