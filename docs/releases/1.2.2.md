# Dojo Video Engine 1.2.2

Date: 2026-11-08. Candidate release for all 17 public packages. Registry
publication, signed tag and exact provenance receipts are pending.

## Behavior and compatibility

The default `maxLines` for native text-overlay slots now preserves the number of
authored newline-separated lines. This applies to title cards, lower thirds,
quote cards, stat callouts, announcement banners, social hooks and chapter titles.
Explicit caller `maxLines` overrides still win. Text-box fitting and ellipsis
behavior remain unchanged; this patch does not guarantee arbitrary copy fits.

The fix is source commit `3e753c8006de4ec8c7fe14940a07377eedecd936` and includes
per-slot and macro regressions plus the rendered `title-card-three-line-subtitle`
probe. Scene v1, package APIs, extension contracts and source-clock semantics are
unchanged. Both consumers should adopt exact immutable release bytes; do not use
engine source aliases or restore a vendored renderer.

## Qualification

Build, all 195 preset tests and `pnpm release:full` passed locally on macOS 26.6.2,
Node 20.19.5 and pnpm 10.34.5. The aggregate includes source/type/contract checks,
rendered-line probes and unchanged pixel goldens, independent FFmpeg media checks,
terminal editing, three-browser probes, resource/performance gates and package
smokes. External clean-package validation, hosted CI and publication remain
separate receipts. These checks do not qualify agent intent, external generation
providers or arbitrary visual quality.

Existing package identities passed token-free trusted-publisher verification at
[run 42333719886](https://github.com/PansaLegrand/dojo-video-engine/actions/runs/42333719886).
This release requires no new package bootstrap or provider credential.
