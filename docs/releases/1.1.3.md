# Dojo Video Engine 1.1.3 — candidate

Date: 2026-11-03. Last reviewed: 2026-11-04. Status: local engine gates passed; consumer/release qualification pending.

This patch pins the renderer and export packages to Mediabunny 1.50.3, shared
with both consumers. The previous caret range admitted
1.65.1 in a fresh consumer and caused AAC sample-table repair to reject exports.
There is no Scene/API change and no loosening of AAC validation.

The full gate now packs current engine packages and runs the terminal consumer
with only internal engine tarball overrides. External dependencies resolve from
package constraints, without a media override or inherited consumer lockfile.
It validates the resolved media version, renders/mixes/exports, independently
decodes expected frame/audio content, reopens the saved Scene and rejects invalid
input. The existing registry-only example remains pinned to its published version
until this release becomes available.

The initial 1.46.0 candidate passed local engine gates but failed harness
typechecking because public media types crossed two library versions. It was
superseded before signing/publication. The synchronized 1.50.3 candidate is
passed renewed `pnpm release:full` and `pnpm verify:clean` gates; isolated
consumer qualification follows. The release workflow
must still qualify, sign, publish and verify the exact retained release bytes.
The corpus collector now excludes the independently installed terminal consumer
directory; its manifest/reports are not Scene fixtures and its own gate covers it.
