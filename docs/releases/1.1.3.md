## Verification

Local full-release and clean-consumer gates passed, followed by the hosted
candidate and tag-bound gates, audit, retained-byte verification and provenance
attestation. Anonymous registry reads independently checked all 16 tarballs'
SHA-256/SHA-512 values, licenses and provenance metadata against the final bundle.

The full gate now packs current engine packages and runs the terminal consumer
with only internal tarball overrides. External media dependencies resolve from
actual package constraints with no consumer media override. It verifies clips,
audio gain, export contents, reopening, and invalid-input rejection. The updated
registry-only terminal example also passed on 1.1.3 without an override.

Paired candidate acceptance: harness commit `80860bd` passed 355 tests, typecheck,
production build and 47 browser checks, including three licensed real-footage
workflows. The commercial web candidate at `f1d6dd39` passed typecheck and 528
actual workspace browser checks. After registry installation, the harness again
passed 355 tests/build and the web passed 5,184 tests (232 existing external
integration cases gated). Human viewing/listening acceptance was deferred by the
user and remains pending; these results do not claim production deployment.

All published runtime bytes match the locally tested candidate. Six manifests
have JSON key-order differences, and the agent-tools declaration differs only in
union member ordering; both were checked separately. Consumer locks/provenance
use the final published bytes, not the earlier local tarball hashes.

## Retained findings

The initial 1.46.0 pin passed engine gates but failed isolated harness typechecking
because media types crossed library versions. It was superseded before signing
or publication; 1.50.3 passed the renewed engine and consumer gates. The corpus
collector now excludes the standalone consumer directory, whose package manifest
and generated reports are not Scene fixtures and have their own acceptance gate.

GitHub could not allocate macOS runners on the first attempts. Retries used the
same immutable candidates; no release gate or signature requirement was bypassed.
A transient local TLS read was retried read-only before writing consumer updates.

Local evidence remains under `test-results/published-1.1.3/`,
`test-results/consumer-web-1.1.3/`, `test-results/registry-runtime-comparison.json`,
and the harness's `test-results/engine113-real/` and `engine-packages/` directories.
