Publication rebuilt the same commit through the full gate. All code and package

JSON key order. Registry integrity checks use the final publication bundle's exact
bytes. Anonymous checks confirmed all 16 packages' SHA-512 integrity, MIT license

Sigstore initially timed out during tag signing; its successful retry produced
the immutable tag above. npm then stopped on a transparency-log conflict after
publishing one package. A registry check identified the 15 missing packages; the
publish-job retry reused the retained bundle and skipped the existing identical
package. No version or release tag was overwritten, and no persistent npm token
was introduced.

The fix was found by exporting a real harness rehearsal with a violet countdown,
video clips and title overlays. Source/render evidence is separate from model
quality, commercial deployment, and broad human acceptance.
