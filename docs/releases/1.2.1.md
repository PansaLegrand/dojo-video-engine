## Delivered behavior

Bounded SVG import through `@dojo-video-engine/interchange/svg` preserves editable
named vector parts. The optional `@dojo-video-engine/three` package validates
3D objects, materials, camera and animation data, with matching preview/export
registration. Trim/split source-time controls preserve animation phase. Scene v1
and existing APIs remain compatible; arbitrary JavaScript, general SVG/CSS/SMIL,
external 3D assets and cross-GPU pixel identity are outside this release.

## Publication recovery

The immutable 1.2.0 tag was not published: its preflight used a dist-tag endpoint
that returned HTTP 401 for the new package identity. Version 1.2.1 reads the public
package document, where absence is HTTP 404; other authorization failures still
fail closed. All public packages advanced together rather than moving the tag.

The first 1.2.1 publishing attempt uploaded and verified all 17 packages and
promoted every latest tag. npm then rejected the bootstrap token's deletion of
the temporary Three.js candidate tag. Cleanup uses the new package's protected
trusted publisher and retained package files; see the publication workflow's
latest attempt for completion. Existing versions must never be overwritten or
repacked for a retry. Token-free publisher verification and bootstrap revocation
remain separate release steps in the runbook.
